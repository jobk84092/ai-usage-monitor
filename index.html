One-time setup

This file is the launcher/readme page. A plain HTML file cannot read your signed-in Cursor, ChatGPT, and Ollama pages. The extension provides that browser connection and stores parsed usage snapshots locally in each browser profile.

Install the extension folder that contains manifest.json. Choose the project folder you extracted, or the folder where you saved the project.
  1. In Chrome, open chrome://extensions and enable Developer mode.
  2. Choose Load unpacked and select the folder containing manifest.json.
  3. Click the AI Usage Monitor toolbar icon to open the dashboard. Sign in to the provider sites in this browser profile, click Sync now, then pin the dashboard tab if you want it always visible.
Firefox: load manifest.json through about:debugging → This Firefox → Load Temporary Add-on. That temporary install is removed when Firefox closes; persistent installation still needs Mozilla signing.

What the accounts actually expose: Cursor and Ollama show plan-specific usage meters. The ChatGPT Usage page exposes Codex/Work/Workspace Agents/ChatGPT for Excel limits and explicitly excludes ordinary ChatGPT conversations. The dashboard keeps these units separate; it cannot produce exact subscription token totals across services.

No prompts, passwords, API keys, or request payloads are collected. See README.md for details and troubleshooting. The old manual ledger is preserved as manual-ledger.html.
